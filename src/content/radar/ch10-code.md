## 一、章节概述

杂波( Chap 9 )与运动目标在幅度上往往相当甚至更强,单纯靠提高发射功率无法解决。MTI( Moving Target Indication )和脉冲多普勒( PD )雷达利用**杂波与目标的多普勒频移差异**,通过滤波器组在频域把它们分开。

**学习目标**
- 掌握单延迟线对消器、双延迟线对消器及参差 MTI 的频率响应;
- 理解"盲速"的产生机理及参差 PRF 消除盲速的原理;
- 评估本振相位噪声对 MTI 改善因子的限制;
- 理解脉冲多普勒雷达的滤波器组设计思想( 7 个 .m 文件中已涉及滤波器概念基础 )。

## 三、核心代码详解

### 3.1 `Fig10_8.m` —— 单延迟线对消器频率响应

单延迟线对消器的脉冲响应 `h[n] = δ[n] - δ[n-1]`,频率响应为:
$$
H(f) = 1 - e^{-j2\pi f T} = 2j\sin(\pi f T)e^{-j\pi f T}
$$
$$
|H(f)|^2 = 2(1-\cos(2\pi f T)) = 4\sin^2(\pi f T)
$$

实际系统受**杂波稳定性**影响,稳定性因子 K(杂波起伏方差/杂波功率)进入分母:

$$
|H_K(f)|^2 = \frac{2(1-\cos(2\pi f T))}{(1+K)^2 - 4K\cos(2\pi f T)}
$$

```matlab
fofr = 0:0.001:1;                  % 归一化多普勒频率 f/fr
arg = 2*pi*fofr;
nume = 2*(1 - cos(arg));           % 分子 |H(f)|²

% K = 0.25 (杂波相对稳定)
den11 = 1 + 0.25*0.25;  den12 = 2*0.25*cos(arg);
den1  = den11 - den12;
resp1 = nume ./ den1;

% K = 0.7 (中等不稳定)
resp2 = nume ./ (1+0.49 - 2*0.7*cos(arg));

% K = 0.9 (杂波很不稳定)
resp3 = nume ./ (1+0.81 - 2*0.9*cos(arg));

plot(fofr, resp1, 'k', fofr, resp2, 'k-.', fofr, resp3, 'k--');
```

**关键现象**
- **凹口位于 f=0, fr, 2fr, ...**:对消器对零多普勒(静止杂波)完美抑制;
- **峰值位于 f=fr/2, 3fr/2, ...**:目标回波增益最大;
- **K 越大,凹口越浅**:杂波谱越宽/越不稳定,杂波"溢出"凹口,MTI 抑制能力下降。

### 3.2 `Fig10_10.m` —— 参差 MTI 消除盲速

普通 MTI 在 f = n·fr 处是"盲速"(第一盲速 = λ·fr/2,目标被对消)。**参差 PRF** 是经典解决方案:用多个不同 PRI 组成发射序列,使多个 MTI 凹口错开,平均后第一盲速被推到很远的距离。

**参差比**:25:30:27:31(每段 1 ms 量级,总周期 25+30+27+31 = 113 ms)

```matlab
k = 0.00035/25;
a = 25*k;  b = 30*k;  c = 27*k;  d = 31*k;
v2 = linspace(0, 1345, 10000);
f2 = 2*v2/0.0375;                   % 多普勒频率, lambda=0.0375 m (X 波段)

% 两脉冲参差 MTI(每组单延迟对消)
T1 = exp(-j*2*pi*f2*a);
X1 = 1/2 * (1-T1).*conj(1-T1);
% T2, T3, T4 同理 (b, c, d)
H_2pulse = 10*log10(abs((X1+X2+X3+X4)/4));   % 4 组平均

% 四脉冲参差 MTI(三次对消,二项式加权 1:3:3:1)
T1 = exp(-j*2*pi*f4*a);
T2 = exp(-j*2*pi*f4*(a+b));
T3 = exp(-j*2*pi*f4*(a+b+c));
X1 = 1/20 * (1 - 3*T1 + 3*T2 - T3).*conj(...);   % 1:3:3:1 二项式
% 4 组平均
H_4pulse = 10*log10(abs((X1+X2+X3+X4)/4));
```

**对比意义**
- **两脉冲参差**:凹口数 = 4,通带波动较大;
- **四脉冲参差**:凹口更深、通带更平,改善因子更高;
- **第一盲速**都已被推到 1345 m/s 之外(原单延迟线第一盲速约 0.7 m/s 量级,因 fr=1/(25k)=1/(25·0.000014)=2.857 kHz,所以盲速=λ·fr/2=0.053 m/s,这就是为什么要参差!)。

**注意**:教材中 1345 m/s 对应 X 波段( λ=0.0375 m, fr=2.857 kHz 时第一盲速仅 53 m/s),参差后盲速提升到约 1700 m/s。

### 3.3 `Fig10_22.m` —— 本振相位噪声 PSD 幂律拟合

实际本振(磁控管、频率合成器)输出并非理想单频,存在相位噪声,通常用幂律模型:
$$
S_\phi(f) = K_0 + K_1/f + K_2/f^2 + K_3/f^3
$$
对数坐标下分段斜率 -10/-20/-30 dB/dec。

```matlab
PSD_f_hz = [1e3  1e4  1e5  1e6  10e6];
PSD_val_dBc_per_hz = [-55  -85 -105 -115  -115];

% 各段斜率
m = (PSD_val_dBc_per_hz(2:end) - PSD_val_dBc_per_hz(1:end-1)) ./ ...
    (log10(PSD_f_hz(2:end)) - log10(PSD_f_hz(1:end-1)));
% 拟合常数
constant = 10.^(PSD_val_dBc_per_hz(1:end-1)/10) .* (PSD_f_hz(1:end-1).^(-m/10));

semilogx(PSD_f_hz, PSD_val_dBc_per_hz, 'bo-', 'Linewidth', 1.5);
gtext('-30dB/decade')     % 1k~10kHz,1/f^3 闪烁
gtext('-20dB/decade')     % 10k~100kHz,1/f^2 白频
gtext('-10dB/decade')     % 100k~1MHz,1/f   白相
```

**关键点**:1 kHz~10 MHz 范围内,MTI 凹口附近(fr ~ 几 kHz)的相位噪声恰好在 -30 dB/dec 段,这是限制 MTI 改善因子的主要因素。

### 3.4 `Fig10_23.m` —— Lorentzian 相位噪声

自由振荡器(磁控管)的相位噪声呈 Lorentzian 形:
$$
L(f) = \frac{1}{\pi}\frac{c_p \pi f_c^2}{(c_p \pi f_c^2)^2 + (f-f_c)^2}
$$

```matlab
fc = 500;                              % 中心频率(此处用归一化频偏)
f  = linspace(350, 650, 300);

c1 = 2e-5;                              % 较不稳定
fc1 = c1*pi*fc^2;
L1f = 1/pi * fc1 ./ (fc1^2 + (f-fc).^2);

c2 = 0.5e-5;                            % 较稳定
fc2 = c2*pi*fc^2;
L2f = 1/pi * fc2 ./ (fc2^2 + (f-fc).^2);
```

`c_p` 越小,振荡器越稳定,谱线越窄(3 dB 带宽 `Δf = c_p·π·f_c`)。

### 3.5 `Fig10_24.m` —— 单极点相位噪声(简化)

```matlab
fb = pi/2;                              % 3 dB 半带宽
f  = 0.01:0.01:100;
Lf = 1/pi * fb ./ (fb^2 + (f-fc+fc).^2);  % 与 Fig10_23 实质相同
semilogx(f, 10*log10(Lf), 'b', 'linewidth', 1.5);
```

等价于 Lorentzian,但用半带宽 `f_b` 参数化。低频段( f << fb )平坦,高频段( f >> fb )以 -20 dB/dec 滚降。

### 3.6 `Fig10_25.m` / `Fig10_26.m` —— 相位噪声限制的 MTI 杂波衰减

**这是 Chap 10 的"实用公式"**:把本振相位噪声代入 MTI 改善因子,得到杂波衰减( clutter attenuation,CA ):

$$
I = \frac{(1/2)(2\pi\sigma_f/PRF)^2}{(1/2)(2\pi\sigma_f/PRF)^2 + \phi_0/\tau}
$$
$$
CA = 10\log_{10}\left(\frac{1}{den}\right) = -10\log_{10}I
$$

其中:
- `σ_f` = 杂波谱宽度(Hz),由杂波内部运动 + 风决定;
- `φ_0` = 本振单边带相位噪声(dBc/Hz);
- `τ` = 脉冲宽度;
- `PRF` = 脉冲重复频率。

```matlab
PRF = 1/400e-6;                          % PRF
taup = 1e-6;                             % 脉宽
sigma1 = 11.93;                          % 较稳定杂波
sigma2 = 20.72;                          % 较不稳定杂波
phi0L = 10^-15;  phi0U = 10^-8;
phi0 = linspace(phi0L, phi0U, 150000);
phi_ratio = phi0 ./ taup;

% sigma1
gns = 1/2 * (2*pi*sigma1/PRF)^2;
CA_NS = 10*log10(1.0 ./ (gns + phi_ratio));

% sigma2
gs  = 1/2 * (2*pi*sigma2/PRF)^2;
CA_S = 10*log10(1.0 ./ (gs + phi_ratio));

x_axis = 10*log10(phi0);
plot(x_axis, CA_NS, 'r-.', x_axis, CA_S, 'b', 'linewidth', 1.5);
legend('σf=11.92', 'σf=20.72')
```

**关键解读**
- **低 φ_0 区(高纯本振)**:CA 受限于 σ_f,曲线呈水平段;σ_f 越大(杂波谱越宽),CA 越高(更易对消);
- **高 φ_0 区(差本振)**:两条曲线收敛,CA 全部受限于本振噪声;
- **工程结论**:为达到目标 CA,需根据 σ_f 决定本振相位噪声要求。例如要求 CA=30 dB、σ_f=12 Hz,则本振 φ_0 应优于 -120 dBc/Hz。

**`Fig10_25` 与 `Fig10_26` 的关系**:教材源代码完全相同,可能对应不同参数或不同 MTI 阶数的二次演示,这里一并保留。

## 四、代码串联叙述

### 4.1 主线:从频率响应到改善因子

```
Fig10_8        [理想单延迟对消器,K=0 时]
    │  频率响应 |H(f)|² = 4 sin²(πfT)
    ▼
Fig10_10       [参差 MTI:消除盲速]
    │  4 组单延迟对消 + 平均 / 1:3:3:1 二项式
    │  改善因子 30~50 dB(典型)
    ▼
Fig10_22~24    [本振相位噪声模型]
    │  幂律拟合 / Lorentzian / 单极点
    │  给出 S_φ(f) 或 L(f)
    ▼
Fig10_25_26    [相位噪声限制下的 MTI 改善因子]
    │  CA = 10 log10[ (½)(2πσf/PRF)² / ((½)(2πσf/PRF)² + φ0/τ) ]
    │  最终工程指标
```

### 4.2 MTI 性能的两大约束

1. **盲速**:由 PRF 决定,普通 MTI 第一盲速 `v_blind = λ·fr/2`,常需参差 PRF 解决;
2. **改善因子上限**:由本振相位噪声决定,改善因子 `I = CA(σ_f, φ_0)` 在 φ_0 差时严重退化。

### 4.3 与 Chap 9 杂波分析的关系

Chap 9 给出"杂波有多强"( CNR ),Chap 10 给出"MTI 能抑制多少"( CA )。**雷达探测能力的总极限 = 雷达方程 SNR - 杂波 CNR + MTI 改善因子 CA**。如果 CA 不能超过 CNR,目标永远淹没在杂波中。

### 4.4 与 Chap 11、12 的衔接

Chap 11 给出随机过程基础;Chap 12 给单脉冲检测(非相干积累);Chap 13 给 Swerling 起伏目标(需要 PD/MTI + 积累);Chap 10 的相位噪声模型将直接影响 Chap 13 中"非相干积累改善因子"的上限。

## 五、关键公式汇总

### 5.1 单延迟线对消器(10.4 节)

脉冲响应:
$$
h[n] = \delta[n] - \delta[n-1]
$$

频率响应:
$$
H(f) = 1 - e^{-j2\pi f T}
$$
$$
|H(f)|^2 = 4\sin^2(\pi f T) = 2(1-\cos(2\pi f T))
$$

考虑杂波不稳定( K 因子):
$$
|H_K(f)|^2 = \frac{2(1-\cos 2\pi fT)}{(1+K)^2 - 4K\cos 2\pi fT}
$$

### 5.2 双延迟线对消器(10.4 节)

脉冲响应:`h[n] = δ[n] - 2δ[n-1] + δ[n-2]`
$$
|H(f)|^2 = 16\sin^4(\pi f T)
$$

### 5.3 参差 MTI(10.5 节)

平均响应:
$$
H_{avg}(f) = \frac{1}{N}\sum_{i=1}^{N}|H_i(f)|^2
$$

二项式加权( 4 脉冲 ):
$$
X_1 = \tfrac{1}{20}|1-3T_1+3T_2-T_3|^2, \quad T_k = e^{-j2\pi f t_k}
$$

第一盲速近似:
$$
v_{blind,1} \approx \frac{\lambda}{2T_{total}}
$$

### 5.4 改善因子(10.6 节)

定义:
$$
I = \frac{(S/C)_{out}}{(S/C)_{in}} = \frac{\bar{G}\cdot CA}{\bar{G}}, \quad CA = \frac{C_{in}}{C_{out}}
$$

单延迟线理论改善因子:
$$
I = \frac{1}{2}\left(\frac{2\pi\sigma_f}{f_r}\right)^2 \cdot \frac{2}{(1+K)^2 - 4K}
$$

### 5.5 本振相位噪声(10.7 节)

幂律模型:
$$
S_\phi(f) = K_0 + K_1/f + K_2/f^2 + K_3/f^3
$$

Lorentzian:
$$
L(f) = \frac{1}{\pi}\frac{f_b}{f_b^2 + (f-f_c)^2}
$$

受相位噪声限制的杂波衰减:
$$
CA = 10\log_{10}\frac{1}{\frac{1}{2}\left(\frac{2\pi\sigma_f}{f_r}\right)^2 + \phi_0/\tau}
$$

### 5.6 盲速(10.5 节)

$$
v_{blind} = n\frac{\lambda f_r}{2}, \quad n = 0, 1, 2, ...
$$

## 六、章节总结

1. **MTI 的本质是"频域高通滤波"**:零多普勒(静止杂波)被凹口滤除,运动目标在通带。Chap 10 的 7 个文件从最简单的单延迟对消器(Fig10_8)开始,逐步引入参差(Fig10_10)、本振噪声(Fig10_22-24)、改善因子(Fig10_25-26)。

2. **盲速是 MTI 的核心矛盾**:由 PRF 决定,工程上必须用参差 PRF 解决。Fig10_10 给出 25:30:27:31 的四脉冲参差,可把第一盲速推到 1700 m/s。

3. **本振相位噪声是 MTI 改善因子的"硬上限"**:即使采用最佳参差比与多脉冲对消,如果本振 φ_0 差,改善因子仍被 Fig10_25 公式封顶。**设计 MTI 雷达时,本振相位噪声要求常由所需 CA 决定**。

4. **MTI 改善因子与杂波谱宽 σ_f 强相关**:σ_f 由杂波内部运动(风、植被摇曳、箔条)决定,**低分辨率雷达 σ_f 较小,MTI 性能对相位噪声更敏感**;高分辨率雷达 σ_f 较大,MTI 更"宽容"。

5. **工程上 MTI 与脉冲多普勒( PD )常常结合**:MTI(单/双/参差对消)先抑制主杂波,再用多普勒滤波器组( FFT bank )精细分辨不同速度目标。Chap 10 代码尚未涉及 PD 滤波器组,但其数学基础(频率响应)已为 Chap 11-13 打下基础。

6. **与 Chap 9 衔接**:Chap 9 的 CNR 与 Chap 10 的 CA 共同决定"目标可见性"。如果 `CA + SNR - CNR > 检测门限`,目标可检测;否则需要 CFAR + 积累 + 跟踪等后续处理。
